# 多光谱烫印图案分割

首次克隆可直接选择 **Release / x64** 生成。**Debug / x64** 另需 OpenCV 4.5.4 的 x64 调试运行库。将匹配的 `opencv_world454d.dll` 放入 `third_party/opencv/x64/vc15/bin/`，或在启动 Visual Studio 前设置环境变量 `OpenCvRoot`，指向同时包含 `include` 和 `x64/vc15` 的 OpenCV 开发目录。构建会将运行库复制到程序输出目录。

在 Visual Studio 2026 打开 [PrintInspector.sln](PrintInspector.sln)，选择 **x64 / Debug**，以 **PrintInspector** 为启动项目，按 **F5**。选择无膜片样品并点击「运行当前组」。左框显示原图，右框可切换轮廓、二值掩膜或前景得分。右侧操作栏「掩膜参数…」可调整孤点去噪和封闭孔洞填补；点「应用并重跑」用当前样品查看效果。滚轮在指针处同步缩放，按住左键拖动，双击恢复适应画框。
