# 有膜片样品试验

生产基准是无膜片图库。此次从“锐视光电/有膜片”实际读取 20 组、每组 8 帧，分别运行八波段森林和四维 PCA 森林。裸露的转运膜片按背景计。使用现有模型和生产默认参数，保存了 40 张原分辨率掩膜及同坐标叠加图。7 组有历史局部标注；目前没有这 20 组的整图精标或对应打印模板。

## 裸膜误提和图文漏提要分开测

3、10、22 号已有人工圈定的裸膜窗口。排除与既有种子标注重叠的像素后，共 70,766 像素。默认阈值下，两条路线在这些窗口均为 0 误提。将各自分类阈值提高 32 重跑，窗口误提仍为 0；部分已标图文的覆盖下降。下表为命中图文的像素数，阈值试验只用于诊断。

| 样品 | 已标图文像素 | 八波段 112 → 144 | PCA 104 → 136 |
|---|---:|---:|---:|
| 3 | 25,017 | 25,015 → 25,006 | 20,966 → 18,662 |
| 10 | 37,077 | 37,077 → 37,042 | 37,077 → 37,077 |
| 22 | 72,657 | 69,321 → 68,335 | 72,657 → 72,334 |

这些数字只代表指定选区。总览中，6 号背景出现明显误提，23 号的浅色文字在两条路线都提取不全。为区分问题是否能通过当前参数处理，又做了以下局部试验。

| 问题与选区 | 默认结果 | 调整结果 |
|---|---:|---|
| 6 号左侧无图文区域，233,800 像素。八波段 | 误提 32,794 | 去噪上限从 96 提至 512 后剩 9,932；单独将分类阈值提至 144 后为 0。该组没有整图参考，不能据此判定主体完整 |
| 同一选区，PCA | 误提 226,986 | 去噪上限提至 512 后仍为 226,986；单独将阈值提至 136 后仍有 224,846。大片相连背景已超出孤点过滤的作用范围 |
| 23 号白光可见的四处浅色笔画内部，共 324 像素 | 两条路线均命中 0 | 将补洞面积、容差调至 2048、100 后仍为 0；单独将阈值降低 32 后也均为 0。放宽补洞确实改变了图中其他位置，但没有找回这些笔画 |

因此，本轮把有膜片结果和试参数据单独保存。6 号可以在八波段路线试用更强的孤点过滤；没有足够的依据把这组设置推广到其他样品。未引入膜片专用分类器或自动识别分支。无膜片的模型、阈值及后处理默认值继续沿用生产基准。

在主界面直接打开「锐视光电/有膜片」即可复看；打开上级「锐视光电」默认进入无膜片分组。原分辨率文件位于 results/有膜片试验/rf8 或 rf4 下。以下命令从工程根目录运行，脚本使用已生成的 Release DLL。

```powershell
$savedData = $env:PRINTVISION_DATA
$savedResults = $env:PRINTVISION_RESULTS
try {
    $env:PRINTVISION_DATA = (Resolve-Path '../锐视光电/有膜片').Path
    $env:PRINTVISION_RESULTS = Join-Path (Get-Location) 'results/有膜片试验'
    python -B evaluation/review_film.py
} finally {
    $env:PRINTVISION_DATA = $savedData
    $env:PRINTVISION_RESULTS = $savedResults
}
```
