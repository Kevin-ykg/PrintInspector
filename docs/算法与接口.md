## 两种随机森林从采集到掩膜

1. 每组读取 UV、B、G、AM、R、FR、IR、W 八张等尺寸 BMP。每帧单独判断格式，支持 8 位灰度、8 位索引色和 24 位彩色，可在同一组混用。24 位 BMP 按 RGB 亮度（约 0.299R + 0.587G + 0.114B）转换为 Gray8 后预览、配准和分类，每个照明波段仍对应一张图。[Stack](../native/print.cpp) 校验步长、容量、通道唯一性，用 W 作坐标基准，在多个窗口比较梯度相位相关。通过一致性检查的整数位移参与采样，最终只保留共同视野。
2. 当前模型用每帧抽样中位灰度作相对亮度参照。八波段路线输入八个相对强度、七个相对 W 的差值和两个 W 纹理量。PCA 路线按训练时保存的均值、尺度及投影生成主成分，再拼接同样的纹理。当前使用四维 PCA。每条路线只调用自身的 RTrees。
3. `ms_run_registered` 按 4 行条带提取特征。随附的数值二分类森林每次对 16 个像素并行遍历同一棵树，尾部逐像素计算。其他受支持的模型使用 OpenCV `getVotes()`。两条路径均将类别 1 的票数除以总票数，再缩放到 0～255。它是得票率，数值越高表示越多决策树支持图案。当前八波段阈值 112，PCA 阈值 104。
4. [refineMask](../native/refine.cpp) 屏蔽与图像边界相连且八波段都很暗的台面，从有效视野抽样估计八个对数光谱比例和整体亮度的中位数、稳健尺度。用光谱相近的相邻像素平滑票数，再融合底布偏离证据。底布样本不足或离散程度过高时回退并标记复核。
5. 八波段路线额外检查浅色区域的强波段偏离。需同时满足该波段有足够灰度、第二波段有响应、整体变亮和原始票数有支持。PCA 路线把图像划成约 96 像素宽的网格，用多数光谱比例接近底布的采样点估计局部亮度。逐行插值后，只降低与局部渐暗布面相符的候选得分。这样能分别处理浅墨漏笔和暗布误提，也允许保留强烈偏离底布的图文。
6. cleanForeground 筛除沿布边的细长分量及弱支持的小点。远离较大图文的独立点小于 24 像素时会被滤除。八波段还会检查紧凑小点在周围底布上是否有重复亮峰，复核方法见[2 号实拍对照](样品复核.md)。fillSmallHoles 只对面积至多 80 像素且仍有证据的封闭区域补洞。所有面积和尺度均基于原分辨率像素，换相机或改变成像倍率时需要重新验证。
7. 最后用 `fitWhiteBoundary` 校正可见边缘。它只在旧掩膜的窄边带内，沿轮廓法线取内外两侧 W 亮度，在对比度足够、两侧平稳时按亮度中点重定边界。逐点校验前景八连通和背景四连通关系，保护笔画连接和内孔。原始树票仍可用于追溯分类。[笔画宽度与中心偏差复核](样品复核.md)

## C# 和 C++ 的约定

入口为 [print.hpp](../native/print.hpp) 与 [Engine.cs](../desktop/Engine.cs)。调用顺序是 ms_load → 一次或多次 ms_run → ms_free。每个工作线程独占模型句柄，WPF 用 SafeHandle 管理生命周期。

| 参数或输出 | 调用约定 |
|---|---|
| Plane[8] | 每帧携带数据指针、字节容量、宽、高、行步长、band。band 0～7 依次对应 UV、B、G、AM、R、FR、IR、W，允许乱序传入。图像在同步调用结束前须保持有效 |
| mask、score、capacity | 调用方提供两个独立缓冲区，每个至少宽×高字节，逐行紧密排列。mask 为最终 0/255 掩膜，score 为模型原始 0～255 得分。输出坐标、方向和尺寸与 W 一致 |
| Result | millis 为原生耗时。foreground 是最终前景像素数。shift、response 是配准诊断量。flags 按位组合，1 为对齐需复核，2 为图文触边，4 为空前景或阈值附近像素较多，8 为底布参照不足 |
| 取消与异常 | cancel 可为空，或指向调用期间有效的 32 位取消标记。返回 0 为成功。失败后在同一线程读取 ms_error 的 UTF-8 消息，丢弃这次输出，可纠正输入后重试 |

WPF 调用 `ms_run_registered`。它在 `ms_run_configured` 的三个掩膜参数（去噪面积上限、补洞面积上限、补洞证据容差）后追加可空的 `int* offsetsXY`。非空缓冲须容纳 16 个 32 位整数，成功后按通道编号给出八对 (dx,dy)。显示 W 坐标 (x,y) 时从该波段取 (x+dx,y+dy)，未覆盖的边缘补零。配准未通过的波段沿用零位移，并保留对齐复核标志。旧 DLL 调用方仍可使用原入口。旧 ms_run 委托同一实现并传入 96、80、46。超出范围会返回错误，参数只作用于本次调用。阈值、原始票率和模型文件独立于这三个后处理参数。详见[界面试调与排查](分割故障排查.md)。

## 样本与模型更新

已有模型包含历史有膜片及无膜片样本，本轮调整的是推理阶段。改变光源、曝光、布面材质或图案覆盖比例，都可能改变错误分布。高票率无法证明未见布料上的准确率。按款式、材料和采集批次留出实物，分别评估漏提、误提、独立小点和细线；已经用来调整规则的 4、5、7、12 号只作为回归样品。

evaluation/sets.json 记录按款式的训练、开发及留出划分。用 `python -B evaluation/annotate.py 12` 在原图上校订参考标签（0 布面背景，1 图文，2 无效台面，255 待确认）。转运膜片本身归背景。evaluation/run.py 优先读 references，然后才使用稀疏种子。运行 `python -B evaluation/run.py train` 会在具备独立训练、开发、留出标注时训练并选择 PCA 维数，默认新模型写至 experiments/无膜片/models。经验证后应把候选模型和对应 settings.json 成套更新。
