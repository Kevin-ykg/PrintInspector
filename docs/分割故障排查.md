# 分割效果异常时怎样调试

## 先在界面试调

选择样品和分割方法，点击左栏「掩膜参数…」。修改后点击「应用并重跑」，右框可切换到二值掩膜或轮廓检查同一位置。先导出默认结果，再按相同位置复测，一次只改一项。参数沿用到当前图库的下一组和批量运行；重新打开目录会恢复默认。导出目录中的 status.txt 记录每次实际使用的三个参数和路线阈值。

| 设置 | 默认值及范围 | 调整时观察什么 |
|---|---|---|
| 去噪面积上限 | 96，0～1024 像素 | 调大允许筛查更大的前景小分量。按是否靠近大笔画、面积和平均证据决定去留；高于上限的分量仍可能受独立的布边规则影响。0 关闭孤点过滤 |
| 补洞面积上限 | 80，0～8192 像素 | 先增大到略高于目标孔洞面积。仅考虑封闭、未碰到屏蔽区的孔；0 关闭补洞 |
| 补洞证据容差 | 46，0～255 灰度级 | 孔内平均融合证据需达到“当前路线阈值减容差”。面积合格但仍有漏孔时，可逐步增大。容差大到超过分类阈值时，面积合格的设计内孔也可能被填平 |

「恢复默认」先还原编辑框，点击「应用并重跑」后生效；「取消」保留原设置和原图。若笔画整段消失，缺口连通到外部背景，调大补洞面积通常无法恢复，应继续查原始投票和光谱证据。

## 用同一处像素找到错误出现的环节

以无膜片 12 号中央标志为例，在左侧选 12 和分割方法，点击「运行当前组」。滚轮放大浅色笔画，用左键拖动定位；分别把左框切到 W、UV、IR，把右框切到「前景得分」「二值掩膜」「轮廓叠加」。切换路线会清除上一结果，需要再次运行。点击「导出当前结果」分别保存两次运行。记录样品、路线和 W 原图上的位置，后续比较都用同一组原始像素。

| 观察位置 | 能回答的问题 | 下一处断点 |
|---|---|---|
| 单个原始波段 | 对同一笔画，哪个波段有可辨识的边界？八张帧里的边界是否位置一致？ | `Stack` 中的 `phaseCorrelate` 和 `offset[b]` |
| WPF 导出的 score.png 或 review.py 的 votes.png | 原始森林是否已把底布打了高分、把笔画打了低分？用原始 Gray8 取值，八波段和 PCA 阈值分别取各自 settings.json | `ms_run_configured` → `Model::features` → `ForestVotes::evaluate`。用 `ms_score_rows` 对照 OpenCV 原始树票 |
| `refineMask` 的 evidence | 平滑树票与底布偏离证据融合后，该像素是否过阈值？ | `cv::compare` 前检查 `input`、`evidence`、`outside`、`weakBackground` |
| mask.png 和 overlay.png | 过阈值的分量是否在空间清理时消失？孔是设计镂空还是真实漏印？ | `cleanForeground`、`fillSmallHoles` 前后分别查看 `local` |

在 VS 选 **Debug / x64**，先在 C# `Engine.Run` 命中，再进入 C++ `ms_run`。若断点为空心，在「模块」确认 PrintVision.dll 和同配置 PDB 来自本次生成目录。对 W 原图的点 (X,Y)，`score[Y*w+X]` 是全幅得分；而细化循环中坐标为 `x=X-common.x, y=Y-common.y`。先确认点位于 common 再设条件断点。条带循环中全局行号为 `top+t`。这能避免在并行循环里对每个像素中断。

## 背景噪点多

1. **区分孤点、织纹和布边。** 在确认没有图文的原分辨率区域分别记录误提像素、连通域面积和位置。碎片数变少也可能是噪点连成一片，所以要同时看面积。图案里真实的点、细字标点另外选区。
2. **得分图已在渐暗布面上发亮。** 对比这些位置和附近净布的各波段。若光谱比例接近、整体亮度逐渐降低，在 PCA 的 `clothBrightnessGrid` 检查网格是否采到足够净布；在 `refineMask` 看 `shade`、`localDeviation`、`first/second`。当前只有 shade>0.7、局部亮度偏差<1.8、两项光谱偏离低于 4.8 和 3.0 时才降权。先检查哪一项不成立，再评估网格大小或降权条件的改变。扩大抑制范围时需同时测暗色墨。
3. **背景得分低，掩膜里却出现小块。** 检查 `distance` 的强光谱恢复以及 `weakBackground`。底布中位数若被大面积图案、拼色面料或反光污染，净布也可能偏离参照。再查 `cleanForeground` 中的面积、与大分量的邻近关系和平均证据。只有干扰确为小孤点时，才考虑调整独立点门槛，并用真实点状图案验证损失。
4. **细线沿画幅或布边延伸。** 在 `exterior` 看八波段最大灰度及与画框边界相连的暗区，再在 `cleanForeground` 看分量到暗区的距离、跨度和厚度。只在白光下很黑的衣料可能在 IR 中明亮。宽度固定的裁边会同时去掉真实靠边笔画，修改后检查跨布边方向的细线。

回归用 4、7 号的两侧空白带和 5 号右侧暗布带。在当前基线上，PCA 对这三处分别误提 149、357、0 像素。对比时保持原图、坐标、模型及阈值一致，同时检查 5 号字边和 7 号细字。[固定选区与对照图](样品复核.md)

## 前景不完整、断笔或孔洞

1. **两条路线在同一边缘均有错位。** 优先检查组内帧的振动、位置、波段文件名及配准标志 1。若多波段的实体轮廓分离，像素特征可能混入两种材料。比较两次重复拍摄，再判断是否需调整采集时序或配准。整组共同旋转对一期分割坐标没有额外影响。
2. **只有一条路线的原始票率低。** 在有差异的波段对比笔画和相邻底布的特征值。八波段看相对灰度及相对 W 差值；PCA 看冻结投影前后是否仍有分离。检查类别 1 的票数与总票，确认选用相应模型和阈值。如果该类墨和布面组合在训练样本中缺失，补充独立标注的图文及邻近布面，按款式重新划分并在开发集选参数。
3. **得分已有响应，最终掩膜仍断。** 查看 `outside` 是否屏蔽了笔画，以及 `evidence` 是否在阈值前被压低。12 号是典型例子。八波段的浅色恢复要求主响应波段灰度至少 32、标准化偏离至少 5，次强偏离至少 1.1，整体亮度高于底布中心 0.8 个稳健尺度，且原始得分至少达到阈值的一半。逐项看失败条件，修改后同时记录补回像素和向背景溢出的像素。
4. **阈值后有细字，清理后消失。** 在 `cleanForeground` 两侧比较同一分量。远离大分量且面积小于 24 像素的独立点会被清除。减小剔除门槛前，先定义真实最小点的物理尺寸与相机成像倍率，并重跑空白布噪点选区。
5. **实心区域有孔。** 先查原始各波段，标出预期实心、设计镂空及疑似真实缺墨。默认配置下 `fillSmallHoles` 仅处理至多 80 像素、有一定证据且与图外隔离的孔。较大漏提应向前追查特征或底布证据。全局增大补洞面积可能把将来要检测的真实缺墨一并填掉。

12 号笔画的 UV/W 光学参照覆盖 17,829 像素，当前八波段覆盖 97.25%，相邻参考背景上有 24 个前景像素。这个局部参照可检验调参方向。对于原始八波段都看不清的归属，保留待确认标签，使用模板或独立精标复核。[参照生成代码](../evaluation/compare_fabric.py)

## 一次只验证一个改动

先保留当前模型、阈值与基准输出。在工程根目录用下列命令把候选结果写进独立目录。review.py 用生产 DLL 跑两条路线；选区脚本需要同一输出目录下的 previous-masks 作为对照。下例把**当前版本**的掩膜作为下一次实验的基线。

```powershell
$trial = Join-Path (Get-Location) ("build/调试-" + (Get-Date -Format 'yyyyMMdd-HHmmssfff'))
$previous = Join-Path $trial 'previous-masks'
New-Item -ItemType Directory -Path $previous -Force | Out-Null
foreach ($route in 'rf8','rf4') {
    Copy-Item -LiteralPath "results/无膜片/$route" -Destination $previous -Recurse
}
$priorResults = $env:PRINTVISION_RESULTS
$env:PRINTVISION_RESULTS = $trial
try {
    .\build.ps1 -Configuration Release
    if ($LASTEXITCODE -ne 0) { throw 'Release 构建失败' }
    python -B evaluation/review.py
    if ($LASTEXITCODE -ne 0) { throw '整组评估失败' }
    python -B evaluation/compare_fabric.py
    if ($LASTEXITCODE -ne 0) { throw '选区对比失败' }
    python -B evaluation/check_refinement.py
} finally {
    $env:PRINTVISION_RESULTS = $priorResults
}
```

核对 fabric-cases.csv 里的前后计数、fabric-cases.png 的笔画边缘和所有组的 overlay.jpg。记录模型版本、唯一改动、收益及受损区域。用 `TP/(TP+FP+FN)` 统计有标注像素的 IoU，背景误提另外报告固定面积中的像素数；稀疏种子无法覆盖全部边界。对已有样品奏效后，再在未参与调参的新款及新布料上验证。
